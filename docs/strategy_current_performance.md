# 競技別の戦略比較 — 2026年10月3日

既存の競馬91行と、共通戦略を流用した競輪・オート・競艇の今回の実験をまとめた。競馬の実時間Paper、事後研究、追加競技の探索実験は分けている。

金額は円、オッズは倍。平均は掛金加重。競馬の判断時平均は返還点を含み、最終平均は非返還点だけを分母にする。競馬の非返還購入点の最終価格は全点確認済み。複勝・ワイドは下限〜上限を保持する。評価競走と購入競走は別列で、的中競走は1点以上の的中を含む競走、的中点は的中した買い目の数。同じ買い目の複数口は1点と数える。複数戦略が同じ券を買うため、行の損益を足してポートフォリオの成績にしない。

「—」は購入なし、対象外、または該当する価格が未確認であることを表す。競輪の締切後価格は提供元のCLOSE_ONLY表示で、FINAL_ONLYの平均最終表示へ置き換えない。払戻は公式の的中払戻表から計算できるため、外れ券の最終価格が未確認でも現金評価は可能である。

## 競輪：10月3日の2競走、91案中88案を評価

朝08:25:52に利用可能な入力と、別競走の13:00:30固定入力を合計した探索成績。後者は表示上の締切13:01の30秒前で、約1分前から取得した全発売券種を使用した。朝の入力は締切直前ではないため、2競走の合計を同じ購入時刻の成績として扱わない。朝の拡張戦略は結果を知った後の実験で、直前競走の候補も計算完了は締切後だった。実時間購入の実績ではない。

今回の競輪入力には単勝がないので、単勝を使う比較方式は2車単の中立確率から求めた1着周辺を使う。主分布は2車単と全3連単から推定し、購入対象を校正から除外する。混合方式が参照した市場も購入対象から除く。零正則化の代わりに1e-8の有限正則化で計算した比較値を使い、厳密な零極限とは区別する。推移3案は鮮度内の前観測がなく対象外。

公式の通常着順と払戻表、部分返還なしのフラグを照合した2競走の個別評価。汎用の例外・返還アダプター完成を意味しない。平均最終表示は未確認で、全購入点の締切後表示を別列に載せた。
