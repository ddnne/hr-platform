# 同時分布を使ったケリー配分の比較

## 結果と限界

10月2日の同じ固定時点・同じ24競走で、馬連9案と馬連＋三連複8案を比較し、全269購入行を保存済み公式払戻・返還で精算した。未精算は0件。混合券種の5案がプラスだったが、**全て同じ三連複1点の8,890円払戻に依存する**。その競走を除くと5案全てがマイナスで、継続的な収益や相関を使う優位性は未確認。

これは結果判明後に追加した条件による探索。候補は精算処理の前に保存したが、前向きの実時間Paper実績には加えない。24競走から勝ったものだけを抽出せず、全案を同じ対象集合で比較した。元の36競走のうち、受信鮮度超過5・入力時点で結果/出走取消あり2・利用不能オッズ5を除外した。追加の三連複条件を満たしたのも同じ24競走だった。

## 購入規則

基本形は、全着順状態について `E_Q[log(1 + 損益 / 資金)]` を最大化する。損益は、当たった全買い目の**表示倍率による総払戻**を足し、全賭金を引いて計算する。例えば馬連1-2と三連複1-2-3は両方当たる場合があり、その状態では両方の払戻を足す。買い目を独立な二値事象として扱わない。

一般の同時結果を使う対数資産の最大化は [Busseti・Ryu・Boyd, Risk-Constrained Kelly Gambling](https://web.stanford.edu/~boyd/papers/pdf/kelly.pdf) の定式化を参照した。今回の実装には同論文の破産・ドローダウン制約はなく、その保証は主張しない。

- 研究資金10,000円は各競走で固定。結果に応じた複利運用ではない。
- 100円刻み・1競走300円まで・最大3点。買わずに現金を残すことも選べる。同じ点に200/300円を配分できる。
- 全額/1/2/1/4は、最適化に使う資金を10,000/5,000/2,500円とする。300円上限を適用した配分を後から掛け算する方式ではない。制約なしなら分数ケリーと同じ関係になるが、整数・上限のある今回は「制約付きの分数ケリー方式」とする。
- 馬連だけの9案は主モデル・7方式平均・7方式で最悪の対数成長を各資金割合で比較。既存の排他的な払戻の全探索を再利用する。
- 馬連＋三連複の8案は主モデル・同一周辺・7方式平均・7方式最悪値を1/2・1/4で比較。7方式は独立した確率推定ではなく、平均には既存アンサンブルも含む。最悪値は有限個のモデルの比較で、統計的な信頼下限ではない。

平均表示オッズは購入額で加重する。最終倍率は次の確定配布の保存待ち。設定上の次回取得は10月3日10:00 JSTで、配布・取得の成功は未確認。**公式払戻から各購入の損益は確定できるが、外れ券の最終倍率は逆算できない**ため、平均最終オッズはnullを保つ。最終倍率は評価だけに使い、購入入力には混入させない。

## インプライド依存構造の扱い

- 単勝・馬単を校正に使った上位3着の分布Qrefから、馬連・三連複とその重複的中確率を合算する。購入する2券種は校正から除く。
- Qmargは各馬・各着順の周辺確率をQrefと一致させる。参照分布の依存構造を変えると、個々の買い目確率も共分散も変わる。両者の差を共分散だけの因果的な効果とは解釈しない。
- 今回の主モデルでは、単勝と馬単だけで識別できない3着の条件付き配分は正則化に依存する。全三連単市場から推定した相関ではない。三連単を校正に使う既存三連複実験とは区別する。
- QrefとQmargで配分が異なったのは1/2で10/24競走、1/4で8/24競走。ただし利益の出た買い目は共通だった。
- 混合券種案でも大半は三連複を選んだ。実際に馬連と三連複を同時保有したのは各案0〜2競走だけ。この標本では券種間の重複を考慮する収益改善を確かめる材料は少ない。

入力は対象・参照券種の全組合せを必須とする。その後の購入探索だけを軽くするため、全価格から「各モデル・各資金割合での100円単独購入の最大対数成長」で各券種6候補を選ぶ。全方式が同じ候補集合を使い、その中の整数配分を全探索する。**候補の選抜は近似で、全買い目の大域最適化ではない**。状態の的中パターンによる集約は払戻分布を保存する正確な圧縮である。
