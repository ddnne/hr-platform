# NAR取得条件 — 2026-09-28確認

## 確認済みの公開資料

- [データ説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)は2026-09-16改訂、10ページ。添付方針書の旧確認日との差分は本書へ記録し、正本の本文は改変しない。
- 2ページの規約リンクと3ページのFAQリンクのPDF注釈はいずれも [利用規約](https://www.keiba.go.jp/terms.html) を参照する。別の専用利用規約は今回確認できなかった。
- 当日データは約2分更新で中間オッズを含み、FAQは当日2分に1回程度・月次1日に1回を上限に推奨。各更新は差分でなく、その時点の全内容。これは全更新時点の履歴配布を意味しない。
- [当日ページ](https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/TodayRaceInfoTop)には当日レース情報・オッズ情報のZIP導線がある。月次URLは生成していない。
- 一般規約には無断転載・複製の制限と異常アクセスの遮断条件がある。クラウドでの私的継続保存に関する明示的な条件は未解決。
- [robots.txt](https://www.keiba.go.jp/robots.txt)をローカルHTTPで取得。`User-agent: *` に `Crawl-delay: 10` と `Disallow: /KeibaWeb/DataDownload/` がある。TodayRaceInfo等も拒否対象。Googlebot向けの扱いをこの収集プログラムへ流用しない。

## 確認できた事実と、こちらの判断

**公開ZIPの通常ダウンロードに事前申請・個別許可が必須だという記載は、確認した公式説明書にはない。** 説明書は公開ページのボタンからZIPを取得する手順と、当日約2分・月次1日1回を上限とする推奨取得頻度を案内している。実際のZIP取得はまだ試していないため、技術的な取得成功も未確認。

一方、一般規約の複製・転載制限と、robotsのDataDownload拒否指定がある。今回の「定期自動取得・非公開クラウド保存」への適用範囲は未解決であり、その自動処理だけをこちらの判断で保留している。NARから申請や契約を要求された事実、NARからアクセスを拒否された事実はない。

robotsは自動クローラへの指示であり、利用許諾や申請制度そのものではない。[RFC 9309 §1](https://www.rfc-editor.org/rfc/rfc9309.html#section-1)もアクセス認可とは区別している。robotsだけから「申請必須」とは判断せず、推奨頻度の記載だけから「無条件に自動取得可能」とも判断しない。

[公式FAQの二次利用欄](https://www.keiba.go.jp/qa.html)には、レース情報の商用利用・改変転載の制限と、情報提供契約を希望する法人・団体向けの相談案内がある。公開ZIPを使う個人研究に同じ契約が必須かは、その記載からは確認できない。データ購入・契約を前提にプロジェクトを組み替えない。

前回の「提供元承認」「問い合わせ確認待ち」という記載は、申請義務を確認したという意味ではなかった。この違いの説明が不足していたため訂正する。問い合わせは未解決点を確かめる一つの方法であり、全開発やPRのマージ条件にはしない。公開資料等で適用関係が解決すれば、問い合わせを必須手順として追加しない。

## 問い合わせを選ぶ場合の下書き（未送信）

[公式FAQ](https://www.keiba.go.jp/qa.html)から案内される[ご意見・ご要望フォーム](https://l-horse.net/anquete/goikengoyoubou)を確認した。記入者名・メールアドレス欄があり、個別回答を保証しない旨の表示がある。送信する場合にはユーザーの明示的な依頼と使用する名義・返信先が必要。ユーザーが対応を検討しているため、送信を前提とした名義・返信先の確認は進めない。

件名：データダウンロード機能の定期取得・私的保存について

地方競馬の研究のため、当日オッズZIPを開催中に約2分間隔で取得し、取得時刻とともにアクセス非公開のCloudflare R2へ保存したいと考えています。複数競走・券種を含む配布物は一度だけ取得し、原本・CSV・買い目・台帳の公開や再配布、実投票は行いません。403・429・CAPTCHA等では停止または指定された待機を行います。

1. 説明書FAQの推奨取得頻度とrobots.txtのDataDownload拒否指定は、この用途へどう適用されますか。
2. 自動取得、原本・観測履歴の非公開保存、Cloudflare上での私的分析に必要な許諾や保存期間の条件はありますか。
3. 正式な取得経路、識別用User-Agent、条件付き取得の推奨、ファイル時刻の意味を教えてください。
4. 時刻別の中間オッズ履歴の正式な遡及取得機能がある場合、その対象期間と仕様を教えてください。

問い合わせ文と公式送信先は準備済み。現時点で問い合わせは送っていない。開発用Cloudflare環境は停止状態で準備できたが、提供元条件の解決とは分けて扱う。
