# 状態 — 2026-10-04

## 現在の収集と公開方針

地方競馬を主対象とし、競艇・競輪・オートレースは将来の検証に備えて蓄積する。複数サイトによる冗長化は後の拡張として保留する。中央は開催・番組の日次発見をCloudflareで確認し、券種別のオッズ予約も共通処理へ接続した。全市場の日次巡回の実測とPaper適合は次の段階に残す。

定常収集と日次の競走発見・予約生成は既存の非公開Cloudflare環境で動かす。端末は有限調査や確認の窓口で、定常処理の常時稼働条件にはしない。競走時刻の見直しは保存した番組情報に従う。表示時刻・受信時刻・実際の受付締切を区別し、締切直前の最後の更新を得たと保証しない。

今後の戦略比較表はチャットと非公開Cloudflare保存に限定する。原本・実データ・買い目・台帳・詳細出力・SecretsはGit、CI、PRへ追加しない。公開済みの古い比較表は過去の確認時点の記録で、最新成績として扱わない。

## 実装した内容

- 当日ZIPと公開ページを共通のHTTP・原本保存・観測履歴へ接続。同値の再観測と同じイベントの再配送を区別する。原本ハッシュの重複排除、保存原本の版付き再解析、利用可能時刻によるas-ofを維持する。
- 追加3競技は提供元ごとに独立した待機・停止を持ち、設定した上限内で並列取得する。予約・日次生成・外部アクセス・R2/D1格納の既存入口を共用する。
- 中央の匿名フォーム・Shift JIS・全市場パーサーを有限予約と日次予約へ接続。単複の保存済み出走情報を、元の取得開始時点までに利用可能だった版から参照する。中央の開催・番組を既存の日次処理で発見し、公式リンクの券種別導線と発走予定を保存する。日次オッズは券種ごとの短いactionとし、単複の完全な中間・平地入力が保存された後に他券種を予約する。待機と同時取得上限は維持し、他3競技の並列Cronも保持する。中央の結果自動タスクはまだ生成しない。
- 中央の収集開始を発走予定の30分前に設定し、予定時刻の変更で見直す。発走予定を収集停止の上限として扱い、受付締切のnullを埋めない。日次の出走情報は利用直前と原本再解析でも中間・平地の条件を確認する。後から得た解析版を元の取得開始時点へ混ぜず、有限調査の最終表示取得は分けて保持する。低頻度設定を全場・全券種2分巡回の保証にしない。
- 中央の公式結果を同じ匿名フォーム・HTTP・原本保存・解析履歴へ接続。要求した導線と本文の競走を照合し、着順と券種別払戻を`RESULT_ONLY`で保存する。保存された公式リンクから他競走の有限取得案を作れ、存在しない導線を生成しない。払戻単位・返還の網羅性を未確認のまま精算適格にせず、日次の結果自動タスクは次の段階に残す。
- HTTP200の空本文を通常の失敗として記録し、拒否と分ける。403等・CAPTCHAの停止と429の待機を維持する。締切による中断と通常の通信タイムアウトも記録上で区別する。
- 下位の同着を元の順位で保持する公式払戻解析を追加。未対応の上位同着・特払い・取止は評価を止める。
- 予約比較を共通化し、JSONの項目順だけが変わる再配送を同じ内容として扱う。配列順・実値変更の検査、イベントID・原本ハッシュ・取得間隔は維持する。
- 対象市場を校正から外す主分布、同一周辺の比較分布、直接換算と発展戦略を共通研究処理で比較する。複数購入、Kelly、相関構造、全市場、推移を扱い、表示価格と事後の最終価格・公式精算を分ける。

## 合成データで確認したこと

全組合せ・数値幅・明示された非数値、別競走や障害競走の拒否、文字コードの不正を確認した。正常取得、同値の再観測、取得失敗、再配送、原本からの再解析、過去as-ofの不変、停止・待機、既存競技との並行保存も試験した。

開催リンクの状態桁と場番号を分け、元の導線を変更せず保持する。状態桁の意味は未確認で、発売状態の判定には使わない。中央の番組にある日本語の時分とHH:mmを共通時計へ変換し、元の表示を保持する。解析版を分け、再解析の新しい利用可能時刻を過去へ戻さない。発走済・中止・未知の表示を時刻へ変換せず、受付締切はnullを保持する。中間・最終表示の券種リンクを読み、別日・別場・競走番号の不一致と重複リンクを拒否する。同場の導線が変わると旧定期予約を終了し、遅れて届く旧番組が時計を復活させないことも確認した。

本文I/Oの一時失敗は解析失敗版として固定せず再試行できる。原本公開後の正規化待ちでも中央の受信後待機を守る。予約の項目順違いは重複として扱い、期限などの実値変更は競合として拒否する。

中央の日次オッズは、1ページが終わると予約枠を返し、他の競走・番組確認も進められる。出走情報の欠測・古さ・未来の利用可能時刻・競走不一致を拒否し、同じイベントの再配送で出走情報や予約数を増やさない。発走予定の変更や中止で旧actionを終了し、旧完了イベントが新しい予定を上書きしない。

中央の結果は8券種の払戻表示・同着・取消表示を保持する。特払いを通常の的中組合せに変換せず、欠けた券種を補わない。結果とオッズの履歴を分け、同値の再観測・再配送・原本再解析・後の解析失敗でも古いas-ofが変わらないことを確認した。結果ページの一般的な注意書きを、その競走で発生した特払いとは扱わない。
