# 実装判断

- 正本v0.4は添付と同一。公開仕様の再確認結果はsource_capabilitiesへ追記する。
- 数理はPython/CVXPY/CLARABELの一実装。Workerに移植して二重管理しない。CPU・メモリ実測後のCloudflare数理配置はM3。
- KLの参照結果が同一の着順状態は、最大エントロピー解で必ず同率になる。この同値類を集約して解く。目的関数は変更しない。各馬各着順を固定する比較分布は、各着順の周辺制約への反復比例フィッティング（IPF）で解く。周辺誤差1e-12以下とエントロピー双対ギャップ1e-9以下を要求する。
- 確率・周辺制約許容誤差は1e-7。solverはoptimalのみ受理。微小な負値補正と正規化のL1修正量を保存する。正則化による縮約をモデル誤差として記録し、真値への完全一致を強制しない。
- 日次仮想購入上限は各実験・比較モデルごと10,000円を開始用仮値として設定。1競走100円・1買い目は方針書どおり。実資金・クラウド予算の上限ではない。
- ローカルは内容アドレス付き原本/正規化本体とSQLite索引。原本→索引の順で永続化。解析版・観測・判断を分け、原本の再利用と観測履歴を両立する。
- 取得枠は初期120秒。失敗枠の遅延再試行を、その枠の取得成功へ変更しない。予定枠外の取得自体は観測として保存し、鮮度情報付きのas-of入力になり得る。
- 全券種のCSV行を保持できるが、数理の通常的中行列は単勝・馬単・馬連・三連複・三連単。初期Paperは馬連。三連複は別実験設定が必要。枠・レンジ式・重勝式のPaperは未対応。
- Workerは原本収集に限定。解析失敗・モデル停止と独立して動ける。raw_observationsは取得証拠であり、市場断面のavailable_atは解析接続までnull。市場履歴APIは現在Python Storeにある。Worker→解析→D1市場索引の接続は未実装。
- Workerの公開HTTPは404、workers.devとプレビューURL無効、Cron空、収集と取得条件確認のスイッチはfalse。専用hr-platform-dev-*を作成して停止状態で配置済み。既存の他サービスは変更しない。`SOURCE_APPROVED`は内部の取得条件確認スイッチで、NARの許可証や個別承認を取得した意味ではない。
- 通常fetchの20秒タイムアウト・16MiB圧縮上限、Python側64MiB展開上限・16エントリ・圧縮率上限300を安全上限として置く。公式実ファイルに適するかは未実測。
- 依存関係はuv.lock/package-lock.json固定。旧SciPy 1.15.3のmacOS wheelがロード不能だったため1.18.1へ変更し、数値試験を再実行。Wranglerの依存するMiniflare 5 alphaを同じ版で固定し、公開移行ヘルパーでテスト設定を変換する。

- 初回Linux CIでは比較分布の錐最適化に4.85e-7の状態確率誤差が出た。試験の許容値1e-7は緩めず、上記IPFへ変更し、非一様な指数型分布の解析解とゼロ確率の境界例で照合した。

## 自律実行と人に求める判断 — 2026-09-28

PRは変更・検証・レビューの記録とする。通常の実装についてユーザーにコードの妥当性やマージ可否を逐次確認させない。メインが独立レビューの指摘を評価・修正し、対象コミットのCI、公開境界、競合、適用される保護ルールを確認してマージする。CI失敗は修正作業であり、人の承認で通過させない。マージが運用環境を変更する場合は、その変更も既存の承認範囲に含まれるか確認する。必要なレビュー等を迂回しない。

| 項目 | 担当と扱い |
|---|---|
| 設計、実装、試験、独立レビューの指摘対応、通常のPRマージ | メインが自律実行。PR #1に固有の人による判断事項はなし |
| 実ファイルの互換性、履歴・欠測・数理の未検証点 | 技術作業として検証。未検証を一括して人への確認事項にしない |
| 許可されたdev環境内の準備・停止状態の検証 | メインが自律実行。実収集の有効化とは別に扱う |
| 取得条件の適用範囲が不明 | 根拠の追加調査はメインが行う。不明を申請義務と断定せず、該当自動処理だけ保留 |
| 外部へ問い合わせる場合の送信・使用名義 | ユーザーの明示的な送信依頼が必要。現在は未送信で、対応検討中 |
| 新規契約、課金プラン変更、公開範囲拡大、既存本番への破壊的変更 | 権利義務・支出・影響範囲を具体化してユーザー判断を求める。購入データ・実投票は現スコープ外 |

PR #1のマージは、NARの取得条件が解決したことや、実収集・実時間Paperを開始してよいことを意味しない。マージで動くCIは合成試験とdry-runのみで、デプロイや収集開始を行わない。
