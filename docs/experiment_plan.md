# 初期実験

正本8.6の仮設定はconfigs/research.yamlに保持。新しい探索方針はconfigs/research-shadow.yaml（IRCD-v0.4-exploratory-002）として追加し、数値条件を維持する。初期はEXPLORATORY_SHADOW。
実績評価前にコード・設定・対象場・期間を固定し、FROZEN_PAPERは別版で登録する。
同じ実験名で設定を変えるとエラー。対象馬連を参照校正へ使わない。

- 対象市場の逆オッズ基準、馬単からの単純集計、Qmarg、Qrefを同一競走・as-ofで比較する。
- Qmarg/direct/referenceの台帳は分離し、仮想資金・損益を合算しない。
- as-ofは既知の発走予定-10分、完了期限は+120秒、受信鮮度は300秒。
- 判断時刻前の呼び出しはNOT_DUE。判断を確定した後の延期でも購入を追加しない。
- λ感度1e-6/1e-4/1e-2、2参照市場の重み感度25:75/50:50/75:25を診断する。
- 部分識別の幅は制約上の幅であり、信頼区間ではない。不整合はREFERENCE_INCONSISTENTと記録する。従来設定は見送り、新しいshadow設定では不整合・nullの上下限を保持した仮定付き研究判断を認める。数値失敗は両設定でMODEL_ERRORとして見送る。
- 固定倍率0/10/20%下落シナリオはscenario_only。精算は払戻・返還の別入力のみ。
- 合成コマンドは架空時計で再現する。実時間の証拠と混在させない。

新しいshadow方針は既存の探索サンプルを見て設計したもの。過去判断へ適用せず、以後の実時間判断を別版へ記録する。詳細と禁止条件は[実データ手順](real_data_runbook.md#参照市場が整合しない場合の研究方針)。

## 取得証跡を使う将来のPaper入力

`paper-plan`は既存の探索設定を複製し、実験名に`:observed-entries-v1`を付けて固定する。
元の数理・金額・時刻・参照不整合方針は変えない。入力方針は`prospective.POLICY`に一元化し、
設定全体を計画と判断へ保存する。`FROZEN_PAPER`への適用は禁止する。

- 判断時刻より前に競走・予定・設定を登録する。未判断の予定変更は、判明時点の証跡に基づき履歴付きで更新する。
  新しい判断時刻が既に過去なら見送り。判断後の延期では再購入しない。
- 固定時点までに利用可能だった当日競走ZIP、単複ページ、対象・参照オッズを照合する。
  競走情報と状態表示も受信300秒以内を要求する。計画登録に使った古い予定だけでは判断できない。
- 結果欄あり、最終表示、予定不一致、馬番/頭数不一致、除外・取消・未知の変更表示は見送る。
  馬番の一致と全買い目の完全性は別に検査し、ゼロ・欠損を理由に馬を落とさない。
- `LISTED_NOT_REPORTED_WITHDRAWN`は「両方の一覧に載り、変更表示がない馬を候補とする」という仮定。
  生データの`active=null`を変更しない。将来予定より前の時刻付き表示を観測し結果欄がないことを、
  `OBSERVED_CLOCK_BEFORE_KNOWN_SCHEDULE_WITHOUT_RESULTS`として記録する。
  実際の出走確定・発売受付・全ての中止告知の網羅を保証するものではない。
- 日付のない`HH:MM現在`から更新日時を作らず、`source_updated_at=null`を維持する。
  受信鮮度は提供元の更新鮮度とは異なり、同じZIPも券種間の完全同期の証明にはしない。
- 判断は原観測・解析ID・受信/利用可能時刻・派生入力・仮定を保持する。
  後の結果や出走変更で書き換えず、公式払戻/返還による精算を待つ。
- 計画は保存完了後の利用可能時刻を持つ。登録保存が判断時刻を越えた場合も見送り、開始時刻へ戻さない。

最初の実証には、将来の固定時点にそろった新鮮な実入力が必要。未明の表示確認や`NOT_DUE`は
実Paper判断・購入・精算の成功に数えない。取得の自動起動とCloudflareへの接続は未完了。

入力仮定の背景は、[公式の出馬表・オッズの案内](https://www.keiba.go.jp/beginner/step2.html)と
[公式FAQの画面更新案内](https://www.keiba.go.jp/qa.html)。これらを実際の出走確定や行別更新時刻の保証へ拡張しない。

固定評価の対象場・評価期間は未選定。取得品質で決め、収益を見て選ばない。
実結果校正、期間分割、開催日ブートストラップ、ドローダウン等の複数競走評価はM4で未実装。

## 単勝＋馬単の校正差を分ける診断

主モデル・Qmarg・直接換算の三比較は維持する。以下は第四の購入戦略ではなく、主モデルの処理が作る差を説明する解析的な基準である。

単勝の正規化逆オッズを `w_i`、馬単を `a_ij`、馬単の1着周辺を `a_i = sum_j a_ij` とする。単勝への重みを `alpha`（0より大きく1未満）とし、正則化を外した前向きKL目的関数は、KLの分解により

```
alpha * KL(w || r) + (1-alpha) * KL(a || p)
= alpha * KL(w || r) + (1-alpha) * KL(a_first || r)
  + (1-alpha) * sum_i a_i * KL(a_second_given_i || p_second_given_i)
```

となる。したがって最適な1・2着の同時確率は

```
r_i = alpha*w_i + (1-alpha)*a_i
p0_ij = r_i * a_ij/a_i
```

で得られる。馬連確率は `p0_ij + p0_ji`。3着はこの二市場では特定されず、ここでは残る馬への一様分配を最大エントロピーの選択として明示する。新しい3着情報を得たとは解釈しない。

現在の等重み設定では `alpha=0.5`。対象馬連のオッズはこの計算へ使わない。参照市場が整合していれば、この基準は馬単の直接換算と一致する。

各馬連について次を保存する。

- `reference_market_adjustment = p_unregularized - p_direct`：参照市場間を調整する際の確率差。
- `regularization_adjustment = p_ref - p_unregularized`：正の正則化と数値解の誤差を含む残差。

二つの和は `p_ref - p_direct`。既存の `d_price = d_dep + d_rest` とは別の分解であり、実際の市場変動の原因や利益を同定するものではない。主モデルの正則化・重み・購入閾値、識別制約の許容差は変更しない。

検証には非整合な合成市場を使い、重み3設定について独立した凸最適化結果の馬単・馬連・単勝確率と絶対誤差2e-6以内で照合する。目的関数が特定しない3着方向を除いた変数で最適化し、solver状態optimalを要求する。実行モデルの許容誤差を緩める変更ではない。
