## 三モデルを同じ市場確率で比較する

正本7.3の通り、通常の馬連・三連複など、的中事象が排反で全買い目が揃う券種では、
観測倍率を `O_i` とし、どの買い目も同じ期待払戻倍率 `C` になる条件から市場基準を作る。

```
v_i O_i = C,  sum_i v_i = 1
C = 1 / sum_i (1 / O_i)
v_i = (1 / O_i) / sum_j (1 / O_j)
```

`C` は券種・断面ごとに求める。期待払戻が等しいという仮定であり、`C=1`や真の的中確率を意味しない。
丸め・非同期・市場の偏りは残る。複勝・ワイドの複数的中事象やレンジ表示には、この正規化をそのまま適用しない。

| 比較する確率 | 算出方法 | 同じ対象市場との比較 |
|---|---|---|
| 主モデル `p_ref` | 対象券種を除く市場から推定したQrefを対象事象へ合算 | `p_ref - v_target`、`p_ref / v_target` |
| 同一周辺 `p_marg` | Qrefと同じ各馬・各着順周辺を持つQmargを合算 | `p_marg - v_target`、`p_marg / v_target` |
| 直接換算 `p_direct` | 正規化した馬単を馬連へ合算。三連複では三連単を合算 | `p_direct - v_target`、`p_direct / v_target` |

すべて同じ競走・判断時点・出走集合・買い目集合を使う。主モデルの差は既存の
`log(p_ref/v_target) = log(p_ref/p_marg) + log(p_marg/v_target)`で依存寄与と残りへ分ける。

収益評価では、各モデルの確率 `q_i` に対して `q_i O_i - 1 = C(q_i/v_i) - 1`。
同一市場内の確率比と期待払戻の順位は一致するが、確率比が1を超えるだけでは購入条件を満たさない。
例えば市場10%・モデル12%・倍率8倍なら、市場基準より確率が高くても期待払戻は96%となる。
判断後の倍率変化は別に評価し、実際の精算は公式払戻・返還を使う。最終倍率を判断入力へ戻さない。

この確率基準は既存実装の説明を明確にしたもので、登録済み設定や判断は変更しない。
2026-09-30の固定済み8競走のうち分布がある4競走で、正規化・期待払戻との恒等式・
確率比による候補と三モデルの固定判断の一致を確認した。残る4競走はモデル未評価の見送りとして保持する。
追加取得・再推定・Paper書込みは0件。結果に対する確率評価は下記のBrier・対数損失で行う。

## 取得証跡を使う将来のPaper入力

`paper-plan`は既存の探索設定を複製し、実験名に`:observed-entries-v1`を付けて固定する。
元の数理・金額・時刻・参照不整合方針は変えない。入力方針は`prospective.POLICY`に一元化し、

- 判断時刻より前に競走・予定・設定を登録する。未判断の予定変更は、判明時点の証跡に基づき履歴付きで更新する。
  新しい判断時刻が既に過去なら見送り。判断後の延期では再購入しない。
- 固定時点までに利用可能だった当日競走ZIP、単複ページ、対象・参照オッズを照合する。
  競走情報と状態表示も受信300秒以内を要求する。計画登録に使った古い予定だけでは判断できない。

  馬番の一致と全買い目の完全性は別に検査し、ゼロ・欠損を理由に馬を落とさない。

  状態解析v6から、空欄に加えて完全一致の「騎手変更」を、出走取消を示さない既知ラベルとして分類する。
  複合表示は引き続き未知とし、この分類は新しい解析結果の利用可能時刻以後にのみ使う。
  解析版と元の表示を判断へ保存し、旧版による見送りや過去のas-ofは書き換えない。
  生データの`active=null`を変更しない。将来予定より前の時刻付き表示を観測し結果欄がないことを、

  実際の出走確定・発売受付・全ての中止告知の網羅を保証するものではない。
- 日付のない`HH:MM現在`から更新日時を作らず、`source_updated_at=null`を維持する。
  受信鮮度は提供元の更新鮮度とは異なり、同じZIPも券種間の完全同期の証明にはしない。

## 保存済み確率と公式結果の比較

`compare-paper`の`prediction_scores`は、判断時に保存した全買い目の確率を
単純換算・Qmarg・Qref・対象市場の正規化逆オッズで比較する。購入した買い目だけを採点せず、
各競走を一標本として扱う。モデルを再推定せず、判断記録や購入条件も変更しない。

- 通常の馬連・三連複で、公式精算の正本に単一の的中買い目がある場合に限る。
  同じ照会時点までに利用可能だった、同じ版の精算証跡を全モデルへ使う。
- Brierは全買い目について`sum((p - y)^2)`、対数損失は的中買い目の`-log(p)`（自然対数）。
  平均は競走単位とし、買い目数を標本数へ数えない。的中買い目の確率が0なら、
  対数損失を`INFINITE`と明記して数値欄はnullにする。確率をクリップして有限値へ変えない。
- 支持集合・確率・結果が適合する共通競走集合だけを確率評価する。評価不能の理由と件数を残し、
  モデルごとに異なる競走を平均しない。完全な予測を保存したNO_BETも評価できる。
- 未精算、訂正、返還・取消、複数的中、特払いは区別する。通常の単一結果に適合しない競走も
  元の損益・見送りの集合から削除しない。後の訂正を以前の照会時点へ混入させない。

これは市場インプライドQと結果の予測指標で、実確率Pへの校正や収益性の証明ではない。
対象市場の逆オッズは比較基準で、追加の仮想購入戦略にはしない。

## 単勝＋馬単の校正差を分ける診断

主モデル・Qmarg・直接換算の三比較は維持する。以下は第四の購入戦略ではなく、主モデルの処理が作る差を説明する解析的な基準である。

単勝の正規化逆オッズを `w_i`、馬単を `a_ij`、馬単の1着周辺を `a_i = sum_j a_ij` とする。単勝への重みを `alpha`（0より大きく1未満）とし、正則化を外した前向きKL目的関数は、KLの分解により

```
alpha * KL(w || r) + (1-alpha) * KL(a || p)
= alpha * KL(w || r) + (1-alpha) * KL(a_first || r)
  + (1-alpha) * sum_i a_i * KL(a_second_given_i || p_second_given_i)
```

となる。したがって最適な1・2着の同時確率は

```
r_i = alpha*w_i + (1-alpha)*a_i
p0_ij = r_i * a_ij/a_i
```

で得られる。馬連確率は `p0_ij + p0_ji`。3着はこの二市場では特定されず、ここでは残る馬への一様分配を最大エントロピーの選択として明示する。新しい3着情報を得たとは解釈しない。

現在の等重み設定では `alpha=0.5`。対象馬連のオッズはこの計算へ使わない。参照市場が整合していれば、この基準は馬単の直接換算と一致する。

各馬連について次を保存する。

- `reference_market_adjustment = p_unregularized - p_direct`：参照市場間を調整する際の確率差。
- `regularization_adjustment = p_ref - p_unregularized`：正の正則化と数値解の誤差を含む残差。

二つの和は `p_ref - p_direct`。既存の `d_price = d_dep + d_rest` とは別の分解であり、実際の市場変動の原因や利益を同定するものではない。主モデルの正則化・重み・購入閾値、識別制約の許容差は変更しない。

検証には非整合な合成市場を使い、重み3設定について独立した凸最適化結果の馬単・馬連・単勝確率と絶対誤差2e-6以内で照合する。目的関数が特定しない3着方向を除いた変数で最適化し、solver状態optimalを要求する。実行モデルの許容誤差を緩める変更ではない。

## 単勝＋馬単の正則化目的関数を解く選択肢

`WIN_EXACTA_NEWTON_V1`は、馬連を校正から外し、単勝と馬単の両方へ正の重みを置く場合に限る。
モデルの目的関数と一様事前分布は同じで、計算方法を設定で明示して選ぶ。既定は`CLARABEL`のまま。
既存の実験設定・登録済みPaper計画のsolverを置換せず、新たな研究設定の`solver`と`version`を指定する。
主推定・正則化感度・重み感度はすべて同じ選択を使い、失敗時の自動切替はしない。

完全な異なる3頭の順序付き状態集合では、同じ1・2着を持つ状態へ等しく分配することが
正則化KL項を最小にする。`x_ij`を1・2着の同時確率、`r_i=sum_j x_ij`、`m=n(n-1)`とすると、
`q_ijk=x_ij/(n-2)`で、解く目的関数は次のとおり。

```
lambda * sum_ij x_ij * log(m*x_ij)
+ alpha * sum_i w_i * log(w_i/r_i)
+ beta * sum_ij a_ij * log(a_ij/x_ij)
subject to x_ij > 0, sum_ij x_ij = 1; alpha + beta = 1
```

等式制約付きNewton方向を使う。Hessianは対角成分と1着馬ごとの低ランク成分から計算し、
正値を保つステップ幅を選ぶ。正則化は有限の正数、重みはそれぞれ0より大きく1未満とし、
重複参照・不完全な状態集合・数値異常・反復上限到達は失敗として扱う。

停止には、勾配の最大値と最小値の差が1e-10以下、質量の総和誤差が1e-12以下であることを要求する。
凸性から得られる`gradient @ x - min(gradient)`も記録・検査する。
これは浮動小数点で評価した目的値誤差の診断で、確率誤差の厳密な上界ではない。

既知の正則化最適解を持つ合成市場で確率の絶対差1e-10以下を確認し、全3着状態で独立に評価した
KL目的関数と停留条件も照合する。全状態のCLARABEL解は設定によって1e-7の確率照合に失敗したため、
それだけを正解とする試験は採用していない。旧solverの条件や既存の比較許容値は変更しない。
