# 確率推定と購入戦略の追加比較

## 今回の範囲

確率推定を既存3方式から7方式へ増やし、それぞれ4つの購入規則で比較する。さらに全7方式の見積もりが合意する組合せの案を1つ加え、計29通りとした。既存15案は条件・候補を保持する。新しい29案には従来の最大期待損益に近い対照も含むため、すべてが独立した新戦略という意味ではない。

10月2日の固定入力の研究36競走から、元の適格18・除外12・未到来6をそのまま引き継いだ。分析する18競走は全方式・購入規則で共通。正の期待値等の購入条件で見送りが違うため、購入数と賭金は一致しない。後から都合のよい断面を選ばず、固定時点までに利用可能だった単勝・全馬単・全馬連を使う。

**これは結果判明後に条件を追加した探索で、前向きの収益実績ではない。** 同じデータで多くの案を比較しており、今回プラスの案をそのまま採用しない。設定の別期間検証開始日は10月3日とした。既存の主モデル・三連複研究・実時計Paperへの遡及変更はない。

## 確率を作る7方式

全方式が上位3着の同時分布を持ち、その分布から馬連確率を合算する。購入対象の馬連価格は追加方式の確率推定に使わない。設定は [research-alternatives.json](../configs/research-alternatives.json)、共通計算は [research_alternatives.py](../src/hr_platform/research_alternatives.py)。

| 方式 | 計算・比較する仮説 |
|---|---|
| 主モデル（既存） | 対象市場を校正から除いた既存Qrefを再利用 |
| 同一周辺（既存） | 各馬各着順の周辺がQrefと同じ既存Qmargを再利用 |
| 馬単直接換算（既存） | 正規化した逆馬単オッズを使い、未識別の3着を残りの馬へ均等配分 |
| 単勝PL（追加） | 正規化した逆単勝オッズを強さとし、残る馬から1→2→3着を順に選ぶ |
| 単勝×馬単条件付き（追加） | 1着は単勝市場、2着はその1着馬に条件付けた馬単市場、3着は残る馬の単勝比率 |
| 馬単確率の強調（追加） | 馬単の市場確率を1.2乗して再正規化し、3着は残る馬の単勝比率。高い確率を強める固定仮説 |
| 4方式平均（追加） | 主モデルと追加3方式の同時分布を各25%で平均 |

単勝PLは[Plackett–Luceの逐次選択式](https://hturner.github.io/PlackettLuce/articles/Overview.html)を使う比較基準。元の主モデルを置き換えるものではない。1.2乗や平均の比率は今回の結果から探索していないが、有効な校正と確認した値でもない。原本の0.0、欠落、レンジを有効な価格へ補完しない。

## 購入規則

- **期待損益・1点**：正の期待損益を持つ中から最大の1点を100円。
- **的中確率・1点**：正の期待損益を持つ中から的中確率が最大の1点を100円。
- **利益確率・最大3点**：組合せ全体の期待損益が正という条件で、レース損益がプラスになる確率を最大化。
- **平均と分散・最大3点**：期待損益から `損益分散 / (2 × 仮の研究資金10,000円)` を差し引いた値を最大化し、正の案だけ購入。
- **全方式合意**：全7方式それぞれで組合せ全体の期待損益が正となる案から、利益確率の7方式中の最小値を最大化。

複数点の探索範囲は**各点100円・最大3点・計300円までの全部分集合**。同じ買い目へ200/300円を配分する既存案とは別の規則である。見送りも選べる。日額上限は各比較ごとに時刻順で適用する。賭金・上限・資金・バッチ数は既存の共通設定から参照する。

通常の馬連では複数の買い目は同時に当たらない。その排他性から組合せ全体の損益分布を計算し、的中しても払戻が総賭金以下なら「利益あり」に含めない。全方式合意の最小値はモデル間の比較であり、統計的な信頼下限ではない。

## 確率そのものの比較

同じ18競走の全馬連を使う。購入した点だけを評価せず、Brier・対数損失は小さいほど良い。

| 確率推定 | 競走数 | 平均Brier | 平均対数損失 |
|---|---:|---:|---:|
| 主モデル | 18 | 0.888553 | 2.634610 |
| 同一周辺 | 18 | 0.890952 | 2.662440 |
| 馬単直接換算 | 18 | 0.886705 | 2.614515 |
| 単勝PL | 18 | 0.901643 | 2.745140 |
| 単勝×馬単条件付き | 18 | 0.890951 | 2.656875 |
| 馬単確率の強調 | 18 | 0.889224 | 2.568065 |
| 4方式平均 | 18 | 0.890469 | 2.642306 |

この標本ではBrierは直接換算、対数損失は馬単確率の強調が最小。指標で順位が異なり、利益の出た購入規則と確率推定の良さも一致しない。今後は同じ条件で別期間を評価する。
