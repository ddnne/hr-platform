# 保存済みデータからの発展戦略

## 現状

10月1日の同じ34競走・同じ固定時点の入力を使う比較では、従来の主モデルは33点・3,300円、表示払戻0円だった。選んだ馬連の表示倍率の中央値は294倍、主モデルの的中確率の中央値は約0.61%。主モデルの確率が正しく競走が独立と仮定しても、33点が全て外れる確率は約53%。この計算はモデル上の診断であり、実測勝率や有意差検定ではない。的中0件だけで良否を決められないが、利益を確認できていない。

表示倍率に含まれる控除を二重に差し引かず、判断時点の確率と倍率で `p × O > 1` を確認する。最終倍率は判断に使わない。対象市場を校正から外す主モデル・同一周辺分布・直接換算の比較を維持する。

## 固定した4案

設定は [research-successors.json](../configs/research-successors.json)、計算は [research_selection.py](../src/hr_platform/research_selection.py)。既存の推定結果を再利用する読み取り専用の研究処理で、Paper判断・台帳を書き換えない。

| 案 | 選び方 |
|---|---|
| 従来案 | 既存の主モデルで期待払戻の歪みが最大の1点 |
| 感度を考慮 | 主モデル・正則化なし・既存の正則化/参照重みの別設定の最小確率でも期待払戻が正の1点 |
| 資金の振れを考慮 | 上記と直接換算の小さい方の確率を使い、固定額での期待対数資金増加が最大かつ正の1点 |
| 推移も考慮 | 同じ選び方に、判断より前の2観測で倍率が低下した場合の追加低下シナリオを加える |

最小確率は候補ごとの感度の下限であり、正規化された同時分布でも統計的な信頼下限でもない。これらの下限でBrier・対数損失を計算しない。参照市場の不整合を解消したと解釈せず、その診断値も保存する。

資金の振れを考慮する案は、仮の研究資金10,000円に100円を割り当てた比率 `f=0.01` で、`p log(1+f(O-1)) + (1-p) log(1-f)` を比較する。資金量を実験ごとに探していない。金額は研究上の比較条件で、実投票は行わない。

推移の案は想定締切120秒前と60秒前の既観測値を使い、現在倍率に `min(1, 現在倍率/前倍率)` を掛ける。将来倍率の予測として検証済みではなく、観測済み低下をもう一段置く仮説。同じ観測、鮮度超過、全組合せの不一致、固定数値が揃わない場合はこの案を除外し、補間しない。双方の利用可能時刻が各照会時点以前であることを既存as-of処理で確認する。

この表から除外した非通常着順の2競走は、別途公式ページの払戻・返還を確認した。従来の主モデルは200円に対し払戻0円・返還100円、直接換算と同一周辺は各200円に対し払戻/返還0円。2件だけの公式確認を、上表全体の公式精算や実時計Paper実績へ拡張しない。

## 判断後の価格評価

選んだ後の倍率も、朝に固定した「想定締切10秒前」「想定締切60秒後」の2時点で照合した。後の値で候補を選び直さず、取得が古い場合は除外した。最終性や実際の受付締切は未確認なので、最終倍率の検証ではない。

この診断は全36分析入力の固定候補を使い、上の通常結果34競走の金額表とは範囲が異なる。従来案の35候補のうち、後の受信が古い1点を除く34点では、想定締切10秒前に2点が低下・8点が上昇・24点は同じ観測。最大の低下は判断時倍率の約39.1%までだった。想定締切60秒後では10点が低下した。

資金の振れを考慮した14候補では、想定締切60秒後に7点が低下・5点が上昇・2点が同じ観測。判断時に固定した感度/直接換算の下限確率をその後の倍率へ掛けると、3点は期待収益が非正となった。推移を加えた10候補でも5点が低下し、2点の期待収益が非正になった。これは固定確率に対する価格の診断で、確率の正しさや実現利益を示さない。

保存済み入力・推定結果を再利用し、提供元への追加取得、モデル再推定、候補/台帳の変更は0件。この結果を受けてもv1の条件は変えず、別日の検証で判断後の価格変化を併記する。
