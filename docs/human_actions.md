# 人にお願いする対応

登録・申請・メール・問い合わせ送信は、ユーザーの2026-09-28の指示により人が行う。
通常の開発・検証・レビュー・PRマージはメインが進める。

## 最初の実験用ZIPを取得する

当面は個人研究として、一断面で戦略を比較する。常時運用や利用条件の問い合わせの完了を、このローカル実験の前提にしない。

人が[公式の本日のレース情報](https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/TodayRaceInfoTop)の下部から「オッズ情報」「レース情報」のZIPを各1個、通常のダウンロード操作で取得し、`private/inbox/`へ置く。元のファイル名とZIPはそのまま残す。置いたファイルのパスが分かれば、以後の検査と戦略比較はメインが進める。

今回の確認ではDownloadsに該当するZIPは見つからなかった。エージェントによる自動ダウンロードはrobotsの対象外と確認できないため、単発やブラウザへの切替で例外扱いしない。通常の人のダウンロードにも申請が必要だと判明したわけではない。

取得記録がないファイルは受信時刻をnullにし、静的診断として使う。当日ファイルにも終了済み競走が含まれ得るため、これだけで戦略の有効性を評価しない。ベット時点での有効性検証には、実際にレース前の判断時点までに取得・解析できた中間オッズと推移が必要。最終オッズを判断入力へ使わない。

## 継続収集へ進む段階でNARへ条件を問い合わせる

**申請必須と判明したわけではない。** 公式説明書は当日ファイルの取得頻度を案内する一方、robotsはDataDownloadを自動アクセスの対象外にしている。公開資料から今回の用途への適用を確定できず、当初方針の「明確な自動取得拒否を回避しない」に従って、自動取得だけを止めている。

- 送信先：[公式FAQ](https://www.keiba.go.jp/qa.html)から案内される[ご意見・ご要望フォーム](https://l-horse.net/anquete/goikengoyoubou)。個別回答は保証されていない。
- 人が行うこと：自身の名義と返信先を記入し、以下を送信する。エージェントはフォームを送信せず、登録や有料契約も行わない。
- 返信後：個人情報を除いた回答を共有してもらい、その条件をメインが実装・頻度・保存範囲へ反映する。有料契約を求められた場合は契約せず、購入データ不使用の方針に戻って判断する。

### コピー用の文面

件名：公開データダウンロード機能の自動取得・非公開保存の利用条件について

地方競馬の個人研究のため、公開されている当日オッズZIPを、開催中に約2分に1回、Cloudflare Workersから取得し、非公開のR2へ取得時刻とともに保存することを検討しています。複数競走・券種を含むZIPは一度だけ取得して内部で分配します。データ・原本・買い目の公開や再配布、商用提供、実投票は行いません。アクセス拒否やCAPTCHAでは停止し、429では指定時間待機します。

1. 説明書の推奨取得頻度とrobots.txtのDataDownloadへのDisallowは、この用途にどう適用されますか。自動取得できる正式な経路・条件があれば教えてください。
2. 原本と観測履歴を非公開クラウドへ保存し、私的に分析する用途について、必要な手続き、保存期間などの条件はありますか。
